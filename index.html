☁ Cross-device sync (JSONBin)

Save your ★ starred, ⚑ flagged, and "seen" state to a free JSONBin.io bin so it follows you across devices. Your key is stored only in this browser — it is never committed to the public site. Enter the same Bin ID + key on each device.

  1. Create a free account at jsonbin.io.
  2. Click Create Bin, paste {"starred":[],"flagged":[],"seen":[]}, save. Copy the Bin ID from the URL.
  3. Go to API Keys → Access Keys, create a key with Read + Update permission. Copy it.
  4. Paste both below and click Save & sync.
